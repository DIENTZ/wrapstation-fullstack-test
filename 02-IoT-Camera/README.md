# IoT Camera Capture System
Aplikasi sederhana untuk mengakses dan mengontrol webcam
menggunakan Python dan OpenCV.

## Features
- Real-time camera preview
- Webcam access using OpenCV
- Image capture
- Keyboard capture
- Burst capture
- Configurable camera resolution
- Automatic image filename
- Automatic capture directory

## Technology
- Python
- OpenCV
- Tkinter
- Pillow

## Keyboard Control
| Key | Function |
| C | Capture one image |
| B | Burst capture while holding the key |
| Q | Exit application |
